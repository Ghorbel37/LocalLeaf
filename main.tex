If you can read this PDF, \LaTeX{}, \texttt{latexmk} and Perl are installed
correctly. Double-click anywhere in the PDF to jump to the matching line in
the source, and use \texttt{Ctrl+Alt+J} in the source to jump to the PDF.

\section{Code highlighting}

The block below is rendered by \texttt{minted}, which calls Pygments:

\begin{minted}[frame=lines, linenos]{python}
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("LaTeX"))
\end{minted}
